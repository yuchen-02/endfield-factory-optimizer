# endfield-factory-optimizer

給定目標產出，計算《明日方舟：終末地》產線所需的最少機器數與耗電。

## 這是什麼

玩家常需要手算「要幾台機器才夠」。這個工具把產線抽象成線性規劃問題，
自動求出滿足產出目標、且總耗電最少的機器配置。

## 模型

- **變數**：每個自動化配方要開幾台機器（`x1` = 電驅礦機、`x2` = 精煉爐）
- **條件**：每種物品的「產出速率 ≥ 消耗速率」；目標物品達到指定速率
- **目標**：最小化總耗電

便攜式源石礦機需要玩家手動操作，不納入規劃（`automated: false`）。

範例（目標每分鐘 30 個晶體外殼）：

| 配方 | 機器 | 台數（線性規劃） | 進位 |
|---|---|---|---|
| mine_ore_electric | 電驅礦機 | 1.5 | 2 |
| refine_crystal_shell | 精煉爐 | 1 | 1 |

總耗電：12.5（小數解）／15（進位後）。

## 資料格式

見 `recipes.json`。每台機器有 `automated`、`power`（耗電單位）、`build_cost`；
每個配方有 `machine`、`time_sec`、`inputs`、`outputs`。
配方資料來源：遊戲內數據，整理於 2026-10。

## 執行

    pip install -r requirements.txt
    python solver.py

## 測試

    python -m pytest

測試涵蓋：手算標準答案（`tests/expected.md`）、完美比例（3:2）、
目標為 0、未知物品、缺原料。

## 限制與下一步

- 建造成本（一次性）尚未納入最佳化，只用於事後計算
- 同一產出有多種配方、副產物、迴圈配方尚未處理
